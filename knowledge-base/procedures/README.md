# Knowledge Base — Standard Operating Procedures (SOPs)

Contains verified operational protocols for helpline tele-counselors, supervisors, and administrative officers.

## Core Protocols
- **NHAA 14566 Standard Operating Guidelines**: Inbound call intake, active listening, de-escalation, and call termination procedures.
- **Immediate Crisis Protocol**: Procedures when acute withdrawal, suicidal ideation, or domestic violence is identified during a call.
- **Human Handover Protocol**: Safe warm transfer mechanics between AI voice agent and live human operator.
- **Consent & Privacy Protocol**: Verification of consent for case record creation and referral sharing.
