# SAMVED — Synthetic Evaluation Scenarios

> [!IMPORTANT]
> **SYNTHETIC BENCHMARK DATA ONLY**: All scenarios in this directory are purely synthetic test cases formulated for technical evaluation, pipeline testing, and automated integration benchmarks. None of these scenarios contain real caller data or confidential helpline records.

## Risk Bands Defined
- `scenarios/low`: Informational inquiries, general scheme questions, non-crisis calls (SVI 0–25).
- `scenarios/moderate`: Mild distress, early stage substance concerns, seeking counseling (SVI 26–50).
- `scenarios/high`: Severe withdrawal symptoms, chronic isolation, family breakdown, elevated vulnerability (SVI 51–75).
- `scenarios/critical`: Imminent physical harm, active overdose/acute medical distress, suicidal ideation requiring urgent human takeover (SVI 76–100).
